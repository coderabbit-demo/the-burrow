title: "Controls"

---

The whole game is keyboard-only. WASD and the arrow keys are
interchangeable for movement.

## Movement

| Key | Action |
|---|---|
| `W` `A` `S` `D` | Move (8-directional) |
| `↑` `←` `↓` `→` | Move (alternate) |
| `Shift` | Dodge-roll in your input direction (or facing direction if neutral) |

## Combat

| Key | Action |
|---|---|
| `J` | Light attack — fast, low stamina cost |
| `K` | Heavy attack — slow, high knockback, more damage |
| `L` | Toggle lock-on (nearest enemy in range) |
| `Tab` | Cycle locked target |

## Survival

| Key | Action |
|---|---|
| `F` | Drink Carrot Flask (heal) |
| `E` | Rest at the nearest Grace lantern |

## Menus

| Key | Action |
|---|---|
| `Enter` / `Space` | Start (title screen) |

<Tip>
  Lock-on biases the camera toward your target and lets you strafe
  cleanly around them — invaluable for the spider's leap and every
  Devourer phase.
</Tip>

<Note>
  Attacks and rolls **lock you out of input** for their duration.
  Don't mash; commit, recover, then move.
</Note>
